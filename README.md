# SnapDesktop
A ScreenSaver helper that takes screenshots of the desktop



## Authors

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Copy itself to "%LocalAppData%\Remus RIGO\SnapDesktop"
* Autocheck if auto starts
* Run when user logs in and takes screenshots every minute
* Creates only one screenshot and overwrites it
